CHUYỂN FILE HTML SANG FILE H5P

📄 HTML + Ảnh/Tài nguyên 🎬 Video MP4 + File câu hỏi 🇻🇳 Hỗ trợ tiếng Việt

1. Chọn file HTML

Chọn index.html hoặc index.htm. Mã HTML/CSS/JavaScript được giữ nguyên và đưa vào gói H5P.

2. Ảnh / tài nguyên đi kèm

Chọn ảnh, video, audio hoặc tài nguyên cục bộ mà HTML đang gọi. Có thể chọn nhiều file.

Nếu HTML chỉ có một ảnh nhưng tên ảnh tải lên khác tên trong HTML, ứng dụng vẫn tự ghép khi chỉ có 1 tài nguyên cục bộ.

1. Nạp Video

Chọn video định dạng .mp4. Video sẽ được đóng gói trực tiếp trong H5P.

2. Nạp file câu hỏi

Hỗ trợ .docx, .txt, .md. File cần có mốc “Tại giây … hiện câu hỏi …”, các lựa chọn A–D và dòng “Đáp án: …”.

Trả lời đúng → video phát tiếp. Trả lời sai → bắt buộc chọn lại cho đúng.

Chưa tải file...
Cách dùng: chọn đúng chế độ → nạp file → bấm TẠO FILE H5P. File .h5p sẽ tự tải về máy. Gói tạo ra dùng một H5P library wrapper, lưu media trong content/ và đổi đường dẫn tài nguyên sang URL runtime bằng H5P.getPath().
